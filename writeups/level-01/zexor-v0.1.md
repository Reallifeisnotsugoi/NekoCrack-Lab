## Задача

Нужно либо узнать корректный лицензионный ключ, либо изменить проверку так, чтобы приложение принимало любое значение.

## Восстановление ключа

Открываем список строк в IDA Pro (`Shift+F12`). В секции `.rdata` обнаруживается строка, похожая на лицензионный ключ:

```text
AEXORRBSHA36325S33
```

Проверка этого значения в приложении подтверждает, что это валидный ключ. Обфускации или вычисления ключа в данном варианте задания нет.

## Обход проверки

Для альтернативного решения находим строку:

```text
Invalid license key. Try again!
```

Переход по cross-reference приводит к развилке между сообщениями об успехе и ошибке. Условие реализовано коротким переходом `JZ`, opcode которого начинается с `0x74`. Замена opcode на `0x75` превращает его в `JNZ` и инвертирует результат проверки.

После изменения байта патч нужно применить к файлу через `Edit → Patch program`. Патч предназначен только для локальной копии учебного crackme.
