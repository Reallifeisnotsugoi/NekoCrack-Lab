## Задача

Программа запрашивает имя пользователя и пароль. Нужно восстановить пару значений, которая приводит к сообщению об успешной проверке.

## Анализ

Первичный поиск удобно начать со списка строк в IDA Pro (`Shift+F12`). Строки приглашения `Enter username` и `Enter password` дают быстрый путь к коду, который обрабатывает пользовательский ввод.

Через cross-references на строку с именем пользователя находим функцию проверки. В графе управления последовательно выполняются два сравнения строк:

1. Результат первого сравнения проверяет login.
2. При успехе управление переходит ко второму сравнению — проверке password.
3. Ненулевой результат любой проверки уводит выполнение в ветку отказа; успешный путь заканчивается сообщением `Congrats`.

Значения для обоих сравнений находятся рядом с соответствующими вызовами и не обфусцированы.

## Результат

```text
Login: crackme
Password: RickRoll
```
