# Kryptos — Simple login

| Поле | Значение |
| --- | --- |
| Уровень | 2 |
| Подход | x64dbg и восстановление 32-битного хеша |
| Результат | Password generator реализован на Python |

## Динамическое наблюдение

Breakpoint на `memcpy` позволяет проследить перенос введенного и ожидаемого значений. Для контрольного имени пользователя получена валидная пара:

```text
User: kisikismeowmeow
Pass: 550656006
```

Этого достаточно для подтверждения решения, но не объясняет, как формируется пароль. Следующий шаг — восстановить арифметику функции проверки.

## Алгоритм

Состояние начинается с нуля. Для каждого ASCII-байта имени пользователя:

```text
intermediate = state + character * one_based_index
state = intermediate XOR (intermediate * 8)
```

После обработки всей строки выполняются еще две операции:

```text
password = (state * 0x539) XOR 0x5A5A
```

В оригинале используются 32-битные регистры, поэтому промежуточные значения должны иметь C-подобное знаковое переполнение. Обычные целые Python не переполняются, и без явного приведения результат для части входов будет отличаться.

## Воспроизведение

[`tools/simple_login.py`](../../tools/simple_login.py) реализует точное 32-битное поведение:

```bash
python tools/simple_login.py "kisikismeowmeow"
```

Ожидаемый вывод:

```text
550656006
```

Контрольное значение зафиксировано в unit-тесте и проверяется в CI.
