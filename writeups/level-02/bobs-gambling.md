# prestdayzero — Bob's gambling

| Поле | Значение |
| --- | --- |
| Уровень | 2 |
| Подход | Статический анализ в IDA Pro |
| Результат | Скрытая административная ветка и флаг найдены |

## Анализ меню

После перехода в `main` видны строки пунктов меню:

```asm
lea     rdx, a1AdminTerminal   ; "\n-1: Admin Terminal"
call    sub_1400012B0
lea     rdx, a1PaymentPortal  ; "\n1: Payment Portal"
call    sub_1400012B0
lea     rdx, a2TalkToARepres  ; "\n2: Talk to a representative"
```

Ниже находится дополнительная проверка:

```asm
cmp     al, 0FFh
jnz     loc_140001225
```

Регистр `AL` содержит значение после обработки пользовательского ввода. Константа `0xFF` соответствует 255 без знака и `-1` в знаковом однобайтовом представлении. Экспериментально ввод `225` открывает скрытую ветку; точное преобразование исходного ввода в `AL` еще стоит документировать отдельным фрагментом дизассемблера.

## Результат

После входа в административное меню нужная последовательность пунктов приводит к выводу флага:

```text
dzctf(bob_is_free_1337)
```

Главное наблюдение в этом задании — проверять не только видимые пункты меню, но и сравнения рядом с диспетчером команд, особенно если значение предварительно усекается до младшего байта.
