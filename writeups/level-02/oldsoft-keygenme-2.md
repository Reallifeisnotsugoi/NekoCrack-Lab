## Анализ

Символ `generateSerial(char *)` сразу указывает на функцию, в которой строится корректный serial. После декомпиляции алгоритм сводится к двум числам.

Первая часть зависит только от длины имени:

```text
length_part = 3 * floor(length / 2) + length
```

Вторая часть — накопительная сумма. Для каждого символа добавляются его ASCII-код, индекс с единицы и константа 3:

```text
checksum += character + index + 3
```

Результат форматируется через дефис:

```text
<length_part>-<checksum>
```

## Воспроизведение

Реализация находится в [`tools/oldsoft_keygenme2.py`](../../tools/oldsoft_keygenme2.py):

```bash
python tools/oldsoft_keygenme2.py "username"
```

Например, для имени `A` длина дает `1`, а checksum равен `65 + 1 + 3 = 69`, поэтому serial — `1-69`.

Поскольку алгоритм работает с байтами `char`, скрипт принимает ASCII-ввод и явно отклоняет неоднозначные многобайтовые символы.
