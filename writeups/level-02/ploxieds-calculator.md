# Ploxied — Calculator

| Поле | Значение |
| --- | --- |
| Автор | Ploxied |
| Язык | C/C++ |
| Платформа | Windows x86-64 |
| Заявленная сложность | 2.7 |
| Результат | Ключ получен из поведения программы |

## Наблюдение

Программа содержит anti-debug-проверку, которую можно скрыть с помощью ScyllaHide. Однако для получения ключа глубокий анализ не требуется: после ввода неправильного значения сообщение об ошибке раскрывает ожидаемый ответ.

![Сообщение программы после неправильного ключа](https://github.com/user-attachments/assets/08aa4228-c43b-4c81-90bb-59d540777c1c)

## Результат

```text
[CRACKME] Welcome to system.
>> Enter your license key: CALC-?EVLOSUNAC

[+] Access granted!
[CRACKME] Welcome to calculator.
```

Ключ:

```text
CALC-?EVLOSUNAC
```

Это пример важного принципа: перед декомпиляцией и patching следует полностью исследовать обычное поведение программы. Ошибки интерфейса, логи и диагностические сообщения иногда раскрывают решение напрямую.

## Ограничение разбора

Внутренняя логика anti-debug и механизм проверки ключа здесь не восстановлены. Решение основано на утечке ожидаемого значения через пользовательский интерфейс; отдельный разбор этой логики может дополнить материал позже.
