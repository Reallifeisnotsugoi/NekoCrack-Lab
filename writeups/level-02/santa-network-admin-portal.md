# DonCris — Santa's Network Admin Portal (S.N.A.P.)

| Поле | Значение |
| --- | --- |
| Уровень | 2 |
| Подход | Декомпиляция функции генерации ID |
| Результат | Алгоритм восстановлен и реализован на Python |

## Точка входа

В функции проверки находится вызов с понятным символом:

```asm
call generate_elf_id(std::string const&)
```

Функция принимает имя пользователя и возвращает 32-битный идентификатор. Для генератора достаточно повторить операции над каждым байтом входной строки с точным переполнением по модулю `2^32`.

## Алгоритм

Начальное состояние равно `0xCAFEBABE`. Для каждого ASCII-байта `c` выполняются операции:

1. `state XOR c`.
2. Циклический сдвиг вправо на `(c mod 7) + 1`.
3. Прибавление `0x5AA55AA5`.
4. `state XOR (state << 4)`.
5. Обрезка до 32 бит после арифметических операций.

Финальное значение дополнительно складывается по XOR с `0xDEADBEEF`.

## Воспроизведение

Готовая реализация находится в [`tools/santa_elf_id.py`](../../tools/santa_elf_id.py):

```bash
python tools/santa_elf_id.py "username"
```

Скрипт явно ограничивает ввод ASCII, чтобы его поведение не зависело от кодировки терминала и совпадало с побайтовой обработкой в оригинальной программе.

## Альтернативный подход

Проверку можно обойти изменением условного перехода после сравнения, но восстановление алгоритма полезнее: оно подтверждает понимание функции и позволяет получать корректный ID для любого поддерживаемого имени.
